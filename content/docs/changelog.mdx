## v1.0.1: September 17, 2026

- Bun install commands now use `bun x --bun` instead of `bunx --bun`. `bunx --bun` fails when adding a registry URL. See [Installation](/docs/installation).

## v1.0.0: September 16, 2026

- Published `ButtonGroup`, a component for grouping related buttons with consistent styling, orientation, and separators. See [Button Group](/components/button-group).
- `Button` icons without an explicit `size-*` class now default to `size-4`.
- Added [Styles](/docs/styles) and [variant files](/docs/variants) documentation covering CSS-foundation installation and `cva` recipe authoring.
