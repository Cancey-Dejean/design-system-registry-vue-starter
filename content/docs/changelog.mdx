## October 6, 2026

### v1.1.0

- **Docs:** New [Component flows](/flows) page shows how registry items depend on each other. Choose between three layouts: a registry map, lineage lanes, or an install chain that lists everything `shadcn-vue add` pulls in, in order. Search for an item by name to jump to its flow. The install chain shows each component's props: its variants with their options and defaults, plus the props it declares itself. Open **Detailed list** for a table of every prop with its type and default. Hover a node to preview another item's props. **Props** branches each prop into its own node on the canvas and is on by default; turn on **Options** to list every option with its default. Your layout choice is remembered for the browser session.

## September 17, 2026

### v1.0.1

- **Docs:** Bun install commands now use `bun x --bun` instead of `bunx --bun`. `bunx --bun` fails when adding a registry URL. See [Installation](/docs/installation).

## September 16, 2026

### v1.0.0

- **New:** `Button Group` is a component for grouping related buttons with consistent styling, orientation, and separators. See [Button Group](/components/button-group).
- **Update:** `Button` icons without an explicit `size-*` class now default to `size-4`.
- **Docs:** Added [Styles](/docs/styles) and [variant files](/docs/variants) documentation covering CSS-foundation installation and `cva` recipe authoring.
