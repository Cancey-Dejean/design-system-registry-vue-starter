## October 18, 2026

### v1.2.0

- **Docs:** Added [Introduction](/docs) as the docs entry page and aligned sidebar destinations, audience labels, and section page navigation with the React starter.
- **Fix:** [Installation](/docs/installation) now uses the published `@design-system-ui` namespace, the current Vue docs domain, and the correct registry configuration path.
- **Fix:** Mobile docs navigation closes after choosing a page. Long docs content can shrink within the sidebar layout.

- **New:** Component and block galleries include isolated previews, search, category filters, and grid/list views.
- **Update:** Docs search now ranks matching names, descriptions, categories, dependencies, and source filenames, tolerates typos, and supports keyboard selection.
- **Fix:** Published source imports now resolve to their actual installation targets. Registry manifests include missing direct dependencies, Input Group exports, and the Spinner barrel.
- **Fix:** Restored exported Button types used by dependent components and corrected Attachment action sizing.
- **Update:** Added canonical page metadata, a sitemap, Vue template type-checking, and Storybook test/MCP integration.

- **New:** Published reusable Data Table, Code Block, Direction, Section, Trace, and Questionnaire components with previews and Storybook coverage.
- **New:** Added the numbered Hero blocks and Announcement Bar slider from the React catalog, retaining the original Vue Hero.
- **New:** Published standalone mode/palette controls, Dot Canvas, and composables for clipboard, syntax highlighting, mobile detection, scroll locking, and resize-close behavior.

## October 6, 2026

### v1.1.0

- **Docs:** New [Component flows](/flows) page shows how registry items depend on each other. Choose between three layouts: a registry map, lineage lanes, or an install chain that lists everything `shadcn-vue add` pulls in, in order. Search for an item by name to jump to its flow. The install chain shows each component's props: its variants with their options and defaults, plus the props it declares itself. Open **Detailed list** for a table of every prop with its type and default. Hover a node to preview another item's props. **Props** branches each prop into its own node on the canvas and is on by default; turn on **Options** to list every option with its default. Your layout choice is remembered for the browser session.
