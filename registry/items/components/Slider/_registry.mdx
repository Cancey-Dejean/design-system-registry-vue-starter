Value is a number array—one entry for a single thumb, two for a range. Use `default-value` or
`v-model`, plus `min`, `max`, and `step`.

```vue
<script setup lang="ts">
import { Slider } from "@ui/Slider";
</script>

<template>
  <Slider :default-value="[50]" :max="100" :step="1" class="w-[60%]" />
</template>
```
