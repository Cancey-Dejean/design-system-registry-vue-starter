Use an alert dialog when an action needs an explicit yes or no before it runs — deleting a record,
leaving a page with unsaved edits, or confirming a charge. Compose the parts the same way you would
a dialog: trigger, content, header, and footer with action and cancel.

```vue
<script setup lang="ts">
import Button from "@ui/Button";
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@ui/AlertDialog";
</script>

<template>
  <AlertDialog>
    <AlertDialogTrigger as-child>
      <Button variant="destructive">Delete project</Button>
    </AlertDialogTrigger>
    <AlertDialogContent>
      <AlertDialogHeader>
        <AlertDialogTitle>Delete this project?</AlertDialogTitle>
        <AlertDialogDescription>
          This removes the project and its data. You cannot undo this action.
        </AlertDialogDescription>
      </AlertDialogHeader>
      <AlertDialogFooter>
        <AlertDialogCancel>Cancel</AlertDialogCancel>
        <AlertDialogAction>Delete</AlertDialogAction>
      </AlertDialogFooter>
    </AlertDialogContent>
  </AlertDialog>
</template>
```

`AlertDialogAction` and `AlertDialogCancel` reuse the button variants from the local `button` item,
so install that dependency first (or together) and keep their styling in sync.
